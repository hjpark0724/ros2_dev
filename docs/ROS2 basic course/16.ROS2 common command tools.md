# 16. ROS2 공통 명령행 도구

### 1. 패키지 도구: `ros2 pkg`

패키지를 만들 때 이름, 빌드 형식, 의존성을 지정합니다.

```bash
ros2 pkg create <package_name> --build-type <build-type> --dependencies <dependencies>
```

- C++ 패키지는 `ament_cmake`, Python 패키지는 `ament_python`을 사용합니다.
- C++ 패키지는 보통 `rclcpp`, Python 패키지는 `rclpy` 의존성을 포함합니다.

시스템의 패키지 목록과 특정 패키지의 실행 파일을 확인합니다.

```bash
ros2 pkg list
ros2 pkg executables <package_name>
```

### 2. 노드 실행: `ros2 run`

패키지 안의 실행 파일을 노드로 실행합니다.

```bash
ros2 run <package_name> <executable_name>
```

### 3. 노드 도구: `ros2 node`

현재 도메인에서 실행 중인 노드를 나열하고, 특정 노드의 구독·발행 토픽·서비스·액션 정보를 확인합니다.

```bash
ros2 node list
ros2 node info <node_name>
```

### 4. 토픽 도구: `ros2 topic`

```bash
ros2 topic list
ros2 topic info <topic_name>
ros2 topic type <topic_name>
ros2 topic hz <topic_name>
ros2 topic echo <topic_name>
```

`info`는 메시지 형식과 발행자·구독자 수를, `type`은 메시지 형식을, `hz`는 평균 발행 주기를, `echo`는 수신 메시지를 보여 줍니다.

### 4.1. 토픽 메시지 발행

터미널에서 지정한 토픽으로 메시지를 발행할 수 있습니다. 기본 발행 주기는 1Hz입니다.

```bash
ros2 topic pub <topic_name> <message_type> <message_content>
```

- `-1`: 한 번만 발행
- `-t <count>`: 지정 횟수만 발행
- `-r <Hz>`: 지정 주기로 발행

거북이 이동 속도 메시지 발행 예제입니다. YAML 형식에서 콜론 뒤 공백이 필요합니다.

```bash
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.2}}"
```

### 5. 인터페이스 도구: `ros2 interface`

시스템에 등록된 메시지, 서비스, 액션 인터페이스를 조회하거나 구조를 확인합니다.

```bash
ros2 interface list
ros2 interface show <interface_name>
```

### 6. 서비스 도구: `ros2 service`

현재 도메인의 서비스 목록을 조회하고 서비스를 호출합니다.

```bash
ros2 service list
ros2 service call <service_name> <service_type> <arguments>
```

거북이 생성 서비스를 호출하는 예제입니다.

```bash
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2, y: 2, theta: 0.2, name: 'turtle10'}"
```
