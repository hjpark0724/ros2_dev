# 11. ROS2 파라미터 서비스 사례

### 1. 파라미터 소개

파라미터는 노드의 설정값을 이름과 값으로 저장하는 ROS2 기능입니다. 노드는 파라미터를 선언하고 읽을 수 있으며, 실행 중 명령줄이나 YAML 파일로 값을 변경할 수 있습니다.

```mermaid
flowchart LR
    U[사용자 또는 YAML 파일] -->|설정| P[노드 파라미터<br/>robot_name]
    P -->|읽기| N[ROS2 노드]
    N -->|로그 출력| T[터미널]
```

### 2. turtlesim 파라미터 사용

두 터미널에서 거북이 시뮬레이터와 키보드 제어 노드를 실행합니다.

```bash
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
```

다른 터미널에서 파라미터 목록을 조회합니다.

```bash
ros2 param list
```

`background_b` 파라미터의 설명과 값을 조회하거나 값을 변경할 수 있습니다.

```bash
ros2 param describe turtlesim background_b
ros2 param get turtlesim background_b
ros2 param set turtlesim background_b 10
```

파라미터는 YAML 파일로 저장하거나 불러올 수 있습니다.

```bash
ros2 param dump turtlesim > turtlesim.yaml
ros2 param load turtlesim turtlesim.yaml
```

### 3. 파라미터 노드 예제

### 3.1. 패키지 만들기

```bash
cd workspace/src
ros2 pkg create pkg_param --build-type ament_python --dependencies rclpy --node-name param_demo
```

### 3.2. 파라미터 선언 및 읽기

`param_demo.py`에 다음 코드를 작성합니다. 노드는 `robot_name` 파라미터를 기본값 `muto`로 선언하고 2초마다 현재 값을 출력합니다.

```python
import rclpy
from rclpy.node import Node


class ParameterNode(Node):
    def __init__(self, name):
        super().__init__(name)
        self.declare_parameter('robot_name', 'muto')
        self.timer = self.create_timer(2.0, self.timer_callback)

    def timer_callback(self):
        robot_name = self.get_parameter('robot_name').value
        self.get_logger().info(f'Hello {robot_name}!')


def main(args=None):
    rclpy.init(args=args)
    node = ParameterNode('param_declare')
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

`setup.py`의 `console_scripts`에 진입점을 추가합니다.

```python
'param_demo = pkg_param.param_demo:main',
```

### 3.3. 컴파일 및 실행

```bash
colcon build --packages-select pkg_param
source install/setup.bash
ros2 run pkg_param param_demo
```

다른 터미널에서 실행 중인 노드의 파라미터를 변경합니다.

```bash
ros2 param set param_declare robot_name Robot
```

처음에는 `Hello muto!`가 출력되고, 값을 변경하면 이후 로그는 `Hello Robot!`로 바뀝니다.
