# 18. ROS2 rqt 도구 상자

### 1. rqt 소개

rqt는 Qt 기반의 ROS2 그래픽 도구 모음입니다. RViz2가 로봇·센서 데이터를 3D로 시각화하는 데 중점을 둔다면, rqt는 토픽·서비스·액션·파라미터·로그를 플러그인으로 검사하고 조작하는 데 적합합니다.

### 2. 설치

ROS2 Desktop 설치에는 일반적으로 rqt가 포함됩니다. 최소 설치 환경에서는 rqt와 공통 플러그인을 명시적으로 설치합니다.

```bash
sudo apt install ros-jazzy-rqt ros-jazzy-rqt-common-plugins
```

### 3. 시작

다음 두 방법 중 하나로 rqt를 시작합니다.

```bash
rqt
```

```bash
ros2 run rqt_gui rqt_gui
```

시작한 뒤 상단 메뉴 **Plugins**에서 필요한 플러그인을 추가합니다.

### 4. 토픽 플러그인

**Plugins → Topics**에서 토픽 관련 플러그인을 선택합니다. `rqt_publisher`로 토픽 메시지를 발행하면 터미널 명령 없이 거북이 이동 명령을 보낼 수 있습니다.

먼저 첫 번째 터미널에서 turtlesim 노드를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 run turtlesim turtlesim_node
```

두 번째 터미널에서 rqt를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
rqt
```

1. rqt에서 **Plugins → Topics → Message Publisher**를 엽니다.
2. `/turtle1/cmd_vel`과 `geometry_msgs/msg/Twist`를 선택합니다.
3. 선속도와 각속도 값을 입력해 발행합니다.

### 5. 서비스 플러그인

**Plugins → Services → Service Caller**를 열면 실행 중인 서비스를 찾아 요청을 보낼 수 있습니다.

예를 들어 turtlesim의 `/spawn` 서비스를 선택하고 위치, 방향, 이름을 입력하면 지정한 위치에 새 거북이를 생성할 수 있습니다.

### 6. 파라미터 플러그인

**Plugins → Configuration → Dynamic Reconfigure** 또는 사용 가능한 파라미터 플러그인을 엽니다. 노드의 파라미터를 선택해 실행 중 값을 변경할 수 있습니다.

turtlesim에서는 `background_r`, `background_g`, `background_b` 값을 바꾸어 배경색을 변경할 수 있습니다. 변경한 값은 노드가 지원하는 경우 즉시 적용됩니다.

### 7. 활용 팁

- rqt의 플러그인 목록은 현재 설치된 패키지에 따라 달라집니다.
- rqt와 대상 노드는 같은 `ROS_DOMAIN_ID`를 사용해야 합니다.
- 토픽·서비스·파라미터가 보이지 않으면 먼저 `ros2 node list`, `ros2 topic list`, `ros2 service list`로 대상 노드가 실행 중인지 확인합니다.
