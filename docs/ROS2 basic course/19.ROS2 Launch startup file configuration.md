# 19. ROS2 Launch 시작 파일 구성

### 1. Launch 소개

Launch 파일은 여러 노드를 한 번에 시작하고, 이름공간·파라미터·토픽 리매핑을 함께 설정하는 스크립트입니다. ROS2는 Python, XML, YAML 형식을 지원하며, 복잡한 조건과 로직이 필요할 때는 Python 형식이 가장 유연합니다.

예제를 저장할 Python 패키지를 만듭니다.

```bash
cd workspace/src
ros2 pkg create learn_launch --build-type ament_python
mkdir -p learn_launch/launch
```

### 2. 단일 노드 Launch

`launch/single_node_launch.py`를 만듭니다.

```python
from launch import LaunchDescription
from launch_ros.actions import Node


def generate_launch_description():
    node = Node(
        package='pkg_helloworld_py',
        executable='helloworld',
        output='screen',
    )
    return LaunchDescription([node])
```

`setup.py`의 `data_files`에 Launch 파일 설치 경로를 추가합니다.

```python
import os
from glob import glob

(os.path.join('share', package_name, 'launch'), glob('launch/*launch.py')),
```

빌드하고 실행합니다.

```bash
colcon build --packages-select learn_launch
source install/setup.bash
ros2 launch learn_launch single_node_launch.py
```

### 3. 여러 노드 시작

`multi_node_launch.py`에서 여러 `Node` 액션을 `LaunchDescription`에 넣습니다.

```python
from launch import LaunchDescription
from launch_ros.actions import Node


def generate_launch_description():
    publisher = Node(package='pkg_topic', executable='publisher_demo', output='screen')
    subscriber = Node(package='pkg_topic', executable='subscriber_demo', output='screen')
    return LaunchDescription([publisher, subscriber])
```

```bash
colcon build --packages-select learn_launch
source install/setup.bash
ros2 launch learn_launch multi_node_launch.py
ros2 node list
```

### 4. 토픽 리매핑

`remappings`로 노드의 토픽 이름을 바꿀 수 있습니다.

```python
publisher = Node(
    package='pkg_topic',
    executable='publisher_demo',
    remappings=[('/topic_demo', '/topic_update')],
)
```

실행 후 `ros2 topic list`에서 원래 `/topic_demo` 대신 `/topic_update`가 표시되는지 확인합니다.

### 5. 다른 Launch 파일 포함

`IncludeLaunchDescription`으로 다른 Launch 파일을 재사용합니다.

```python
import os
from ament_index_python.packages import get_package_share_directory
from launch import LaunchDescription
from launch.actions import IncludeLaunchDescription
from launch.launch_description_sources import PythonLaunchDescriptionSource


def generate_launch_description():
    launch_file = os.path.join(
        get_package_share_directory('learn_launch'),
        'launch', 'multi_node_launch.py',
    )
    return LaunchDescription([
        IncludeLaunchDescription(PythonLaunchDescriptionSource(launch_file)),
    ])
```

### 6. 복합 Launch 구성

복합 Launch 파일에서는 `DeclareLaunchArgument`, `LaunchConfiguration`, `GroupAction`, `PushRosNamespace`를 사용합니다.

```python
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, GroupAction
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node, PushRosNamespace


def generate_launch_description():
    background_r = DeclareLaunchArgument('background_r', default_value='0')
    turtle1 = Node(package='turtlesim', executable='turtlesim_node', name='sim', namespace='turtlesim1')
    turtle2 = Node(
        package='turtlesim', executable='turtlesim_node', name='sim', namespace='turtlesim2',
        parameters=[{'background_r': LaunchConfiguration('background_r')}],
    )
    mimic = Node(
        package='turtlesim', executable='mimic', name='mimic',
        remappings=[
            ('/input/pose', '/turtlesim1/turtle1/pose'),
            ('/output/cmd_vel', '/turtlesim2/turtle1/cmd_vel'),
        ],
    )
    return LaunchDescription([background_r, turtle1, turtle2, mimic])
```

실행 후 첫 번째 거북이를 제어하면 두 번째 거북이가 동작을 모방합니다.

```bash
ros2 launch learn_launch complex_launch.py
ros2 run turtlesim turtle_teleop_key --ros-args -r __ns:=/turtlesim1
```

### 7. XML 및 YAML Launch

XML과 YAML도 노드·인자·파라미터·리매핑·포함 기능을 지원합니다. 선언적인 구성이면 XML 또는 YAML을 사용할 수 있고, 조건문·반복문·복잡한 계산이 필요하면 Python을 사용합니다.

XML 예시:

```xml
<launch>
  <node pkg="turtlesim" exec="turtlesim_node" name="sim" namespace="turtlesim1"/>
</launch>
```

YAML 예시:

```yaml
launch:
  - node:
      pkg: turtlesim
      exec: turtlesim_node
      name: sim
      namespace: turtlesim1
```

XML과 YAML 파일도 `setup.py`의 `data_files`에 포함해야 설치 후 `ros2 launch`로 찾을 수 있습니다.

```bash
ros2 launch learn_launch complex_launch.xml
ros2 launch learn_launch complex_launch.yaml
```
