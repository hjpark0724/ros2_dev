# 15. ROS2 시간 관련 API

### 1. 시간 API 소개

ROS2는 반복 실행을 위한 `Rate`와 `Timer`, 현재 시각을 위한 `Clock`·`Time`, 시간 간격을 위한 `Duration` API를 제공합니다.

먼저 예제 패키지를 만듭니다.

```bash
ros2 pkg create learning_time --build-type ament_python --dependencies rclpy
```

### 2. `create_rate`

`Rate`는 루프의 목표 실행 주기를 맞추기 위해 남은 시간을 대기합니다. 주 스레드를 차단할 수 있으므로, 콜백을 사용하는 일반적인 ROS2 노드에는 `Timer`를 권장하며 `Rate`는 별도 스레드나 특수한 제어 루프에 사용합니다.

`rate_demo.py`는 별도 스레드에서 2Hz 루프를 실행합니다.

```python
import threading
import rclpy
from rclpy.node import Node


class RateExampleNode(Node):
    def run_loop(self):
        rate = self.create_rate(2.0)
        count = 0
        while rclpy.ok():
            self.get_logger().info(f'반복 횟수: {count}')
            count += 1
            rate.sleep()


def main(args=None):
    rclpy.init(args=args)
    node = RateExampleNode('rate_example_node')
    thread = threading.Thread(target=node.run_loop)
    thread.start()
    try:
        rclpy.spin(node)
    finally:
        node.destroy_node()
        rclpy.shutdown()
```

### 3. `Timer`

`Timer`는 ROS2 이벤트 루프에서 비차단 방식으로 콜백을 주기적으로 호출합니다. 다음 예제는 1초 타이머와 0.5초 타이머를 함께 사용합니다.

```python
import rclpy
from rclpy.node import Node


class TimerDemoNode(Node):
    def __init__(self):
        super().__init__('timer_demo_node')
        self.counter = 0
        self.create_timer(1.0, self.timer_callback)
        self.create_timer(0.5, self.fast_timer_callback)

    def timer_callback(self):
        self.counter += 1
        self.get_logger().info(f'1초 타이머: {self.counter}회')

    def fast_timer_callback(self):
        self.get_logger().info(f'현재 시각(ns): {self.get_clock().now().nanoseconds}')
```

### 4. 현재 시각 가져오기

`get_clock()`은 노드의 시계 객체를 반환하고, `now()`는 현재 `Time` 객체를 반환합니다.

```python
clock = self.get_clock()
current_time = clock.now()
self.get_logger().info(f'현재 시각: {current_time.nanoseconds}')
```

### 5. `Time`과 `Duration`

`Time`은 특정 시점이고 `Duration`은 두 시점 사이의 간격입니다. 시점끼리는 비교하거나 뺄 수 있고, 시점과 시간 간격은 더하거나 뺄 수 있습니다.

```python
from rclpy.duration import Duration
from rclpy.time import Time

time1 = Time(seconds=10)
time2 = Time(seconds=4)
duration = Duration(seconds=3)

future_time = time1 + duration
elapsed = time1 - time2
past_time = time1 - duration
```

### 6. 빌드와 실행

각 프로그램을 `setup.py`의 `console_scripts`에 등록한 뒤 패키지를 빌드합니다.

```python
'rate_demo = learning_time.rate_demo:main',
'timer_demo = learning_time.timer_demo:main',
'get_clock_demo = learning_time.get_clock_demo:main',
'time_duration_demo = learning_time.time_duration_demo:main',
```

```bash
colcon build --packages-select learning_time
source install/setup.bash
ros2 run learning_time rate_demo
```

다른 예제는 등록한 실행 이름으로 바꾸어 실행합니다.
