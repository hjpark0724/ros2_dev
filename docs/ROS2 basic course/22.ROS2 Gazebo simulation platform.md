# 22. ROS2 Gazebo 시뮬레이션 플랫폼

### 1. Gazebo 소개

Gazebo는 로봇, 센서, 주변 환경과 마찰·탄성·중력 같은 물리 특성을 함께 시뮬레이션하는 3D 플랫폼입니다. 실제 로봇에 적용하기 전 주행·비행·센서·제어 알고리즘을 반복 검증할 수 있습니다.

### 2. 설치 및 운용: ROS2 Jazzy

ROS2 Jazzy는 **Gazebo Sim**과 `ros_gz_sim`·`ros_gz_bridge`를 사용합니다.

먼저 Jazzy용 Gazebo Sim과 TurtleBot3 패키지를 설치합니다.

```bash
sudo apt update
sudo apt install ros-jazzy-ros-gz ros-jazzy-turtlebot3-gazebo ros-jazzy-turtlebot3-description
```

새 터미널에서 ROS2 환경과 TurtleBot3 모델을 설정합니다.

```bash
source /opt/ros/jazzy/setup.zsh
export TURTLEBOT3_MODEL=waffle
```

Gazebo Sim에서 TurtleBot3 World를 시작합니다. 이 터미널은 실행 중인 상태로 둡니다.

```bash
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
```

다른 터미널에서 RViz2를 열려면 동일한 환경을 적용한 뒤 패키지가 제공하는 설정 파일을 사용합니다.

```bash
source /opt/ros/jazzy/setup.zsh
rviz2 -d /opt/ros/jazzy/share/turtlebot3_gazebo/rviz/tb3_gazebo.rviz
```

### 3. Gazebo Sim 실행 확인

시뮬레이션이 실행되면 ROS-Gazebo 브리지와 로봇 상태 발행자가 동작합니다.

```bash
ros2 node list
ros2 topic list
```

TurtleBot3 Waffle 예제에서는 `/scan`, `/camera/image_raw`, `/odom`, `/tf`, `/cmd_vel` 등을 확인할 수 있습니다.

```bash
ros2 topic info /scan --verbose
ros2 topic info /camera/image_raw --verbose
```

### 4. URDF 로봇 모델 만들기

`myrobot` 패키지에 URDF와 Launch 파일을 저장할 수 있습니다. 다음은 기본 큐브 링크를 정의한 `urdf/demo01_base.urdf` 예제입니다.

```xml
<robot name="myrobot">
  <link name="base_link">
    <visual>
      <geometry><box size="0.2 0.2 0.2"/></geometry>
      <origin xyz="0 0 0"/>
    </visual>
    <collision>
      <geometry><box size="0.2 0.2 0.2"/></geometry>
      <origin xyz="0 0 0"/>
    </collision>
    <inertial>
      <mass value="0.1"/>
      <inertia ixx="0.0001904167" ixy="0" ixz="0" iyy="0.0001904" iyz="0" izz="0.00036"/>
    </inertial>
  </link>
</robot>
```

패키지를 만들고 필요한 디렉터리를 추가합니다.

```bash
cd workspace/src
ros2 pkg create myrobot --build-type ament_cmake
mkdir -p myrobot/urdf myrobot/launch
```

### 5. Jazzy에서 모델 추가하기

Jazzy에서는 `ros_gz_sim create` 또는 `ros_gz_sim` Launch API로 SDF·URDF 모델을 Gazebo Sim에 추가합니다. TurtleBot3 예제의 `turtlebot3_world.launch.py`는 Gazebo Sim 시작, 로봇 생성, `ros_gz_bridge`, 이미지 브리지, `robot_state_publisher`를 함께 실행하므로 학습용으로 바로 사용할 수 있습니다.

URDF를 Gazebo Sim에 올릴 때는 Gazebo Sim용 SDF 변환, ROS-Gazebo 브리지, 센서 플러그인 설정이 추가로 필요합니다. URDF 외형을 확인하는 목적이라면 먼저 21장의 `robot_state_publisher`와 RViz2 표시 절차를 사용합니다.
