# 2. ROS2 Jazzy 설치

ROS2 Jazzy Jalisco는 Ubuntu 24.04 (Noble Numbat)를 기준으로 합니다. 아래 절차는 Ubuntu 24.04에서 ROS2 Jazzy 데스크톱 버전을 설치하는 방법입니다.

## 1. 로케일 설정

먼저 현재 로케일이 UTF-8 인코딩을 지원하는지 확인합니다. 다음 명령으로 UTF-8 로케일을 확인하고 설정할 수 있습니다.

```bash
locale  # UTF-8 지원 여부 확인
```

```bash
sudo apt update && sudo apt install locales
```

```bash
sudo locale-gen en_US en_US.UTF-8
```

```bash
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
```

```bash
export LANG=en_US.UTF-8
```

```bash
locale  # 설정 확인
```

> **참고:** 다른 로케일을 사용해도 되지만, 반드시 UTF-8 인코딩을 지원해야 합니다.

## 2. 소프트웨어 저장소 설정

먼저 Ubuntu Universe 저장소를 활성화합니다.

```bash
sudo apt install software-properties-common
```

```bash
sudo add-apt-repository universe
```

다음으로 ROS 2 APT 저장소의 키와 설정을 제공하는 `ros2-apt-source` 패키지를 설치합니다. 이 패키지를 사용하면 ROS 저장소 설정이 새 버전과 함께 자동으로 갱신됩니다.

```bash
sudo apt update && sudo apt install curl -y
```

```bash
export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F'"' '{print $4}')
```

```bash
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
```

```bash
sudo dpkg -i /tmp/ros2-apt-source.deb
```

## 3. ROS2 Jazzy 설치

패키지 목록을 새로 고친 뒤, 설치된 패키지를 최신 상태로 업데이트합니다.

```bash
sudo apt update
```

```bash
sudo apt upgrade
```

ROS, RViz, 예제 및 튜토리얼이 포함된 데스크톱 버전을 설치합니다.

```bash
sudo apt install ros-jazzy-desktop
```

패키지를 빌드하거나 개발할 예정이라면 개발 도구도 설치합니다. 이 패키지에는 `colcon`과 관련 개발 도구가 포함됩니다.

```bash
sudo apt install ros-dev-tools
```

## 4. 환경 설정

Zsh 터미널에서 ROS2 프로그램을 실행하기 전에 다음 명령으로 Jazzy 환경을 불러와야 합니다.

```bash
source /opt/ros/jazzy/setup.zsh
```

새 터미널을 열 때마다 위 명령을 실행해야 합니다. 다음 명령으로 `~/.zshrc`에 추가하면 새 Zsh 터미널을 열 때 자동으로 불러옵니다.

```bash
echo "source /opt/ros/jazzy/setup.zsh" >> ~/.zshrc
```

설정을 즉시 반영하려면 다음 명령을 실행합니다.

```bash
source ~/.zshrc
```

## 5. 발행자와 구독자 예제 노드 실행

ROS2가 정상적으로 설치되었는지 확인하려면 두 개의 터미널을 열고 각각 환경을 불러온 뒤 다음 예제 노드를 실행합니다.

첫 번째 터미널에서 발행자 노드를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 run demo_nodes_cpp talker
```

두 번째 터미널에서 구독자 노드를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 run demo_nodes_cpp listener
```

발행자는 메시지를 전송하고, 구독자는 수신한 메시지를 출력하면 설치가 정상적으로 완료된 것입니다.

## 6. TurtleSim 예제 실행

TurtleSim은 ROS의 핵심 개념을 익히는 데 널리 사용되는 거북이 시뮬레이터입니다.

첫 번째 터미널에서 시뮬레이터를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 run turtlesim turtlesim_node
```

두 번째 터미널에서 키보드 제어 노드를 실행합니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 run turtlesim turtle_teleop_key
```

세 번째 터미널에서는 거북이의 속도 토픽 데이터를 확인할 수 있습니다.

```bash
source /opt/ros/jazzy/setup.zsh
ros2 topic echo /turtle1/cmd_vel
```

## 7. 제거

ROS2 Jazzy 패키지를 제거하려면 다음 명령을 실행합니다.

```bash
sudo apt remove '~nros-jazzy-*' && sudo apt autoremove
```

ROS2 APT 저장소 설정도 함께 제거하려면 다음 명령을 실행합니다.

```bash
sudo apt remove ros2-apt-source
```
