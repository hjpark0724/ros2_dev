# 20. ROS2 기록 및 재생 도구

### 1. Recording and Playback Tools 소개

`bag2`은 ROS2 토픽 메시지를 파일로 기록하고 나중에 다시 발행하는 도구입니다. 실제 로봇에서 문제가 발생했을 때 센서·제어 데이터를 기록해 재현하거나, 다른 사람과 데이터를 공유해 알고리즘을 검증할 때 유용합니다.

### 2. 토픽 기록

기록할 토픽을 발행하는 노드를 먼저 실행합니다.

```bash
ros2 run demo_nodes_py talker
```

새 터미널에서 토픽을 기록합니다.

```bash
# 단일 토픽 기록
ros2 bag record /chatter

# 여러 토픽 기록
ros2 bag record /topic_name1 /topic_name2

# 모든 토픽 기록
ros2 bag record -a
```

출력 디렉터리 이름을 지정하려면 `-o`를 사용합니다.

```bash
ros2 bag record -o chatter_record /chatter
```

기록을 끝내려면 기록 중인 터미널에서 `Ctrl+C`를 누릅니다. 기본 설정에서는 SQLite3 형식의 rosbag2 디렉터리가 생성됩니다.

### 3. 기록 정보 확인

기록 시간, 파일 크기, 메시지 형식, 토픽별 메시지 수를 확인합니다.

```bash
ros2 bag info chatter_record
```

### 4. 재생과 확인

기록된 데이터를 재생하면 원래 노드를 다시 실행하지 않아도 토픽이 발행됩니다.

```bash
ros2 bag play chatter_record
```

다른 터미널에서 재생 메시지를 확인합니다.

```bash
ros2 topic echo /chatter
```

### 5. 재생 옵션

```bash
# 10배속 재생
ros2 bag play chatter_record -r 10

# 반복 재생
ros2 bag play chatter_record -l

# 특정 토픽만 재생
ros2 bag play chatter_record --topics /chatter
```

### 6. 전체 예제

첫 번째 터미널에서 발행자를 실행합니다.

```bash
ros2 run demo_nodes_py talker
```

두 번째 터미널에서 모든 토픽을 기록하고 `Ctrl+C`로 종료합니다.

```bash
ros2 bag record -a
```

기록된 디렉터리를 반복 재생합니다.

```bash
ros2 bag play <기록_디렉터리> -l
```

세 번째 터미널에서 `/chatter`를 구독하면 재생된 메시지를 확인할 수 있습니다.

```bash
ros2 topic echo /chatter
```
