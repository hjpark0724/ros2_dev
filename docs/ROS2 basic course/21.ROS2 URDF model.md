# 21. ROS2 URDF 모델

### 1. URDF 소개

URDF(Unified Robot Description Format)는 ROS에서 로봇의 형상, 물리 속성, 링크 사이의 연결 관계를 XML로 기술하는 형식입니다. URDF는 로봇 모델을 RViz2에 표시하고, TF 좌표계와 충돌 모델을 구성하는 기반이 됩니다.

### 2. 로봇의 구성 요소

일반적인 로봇은 다음 요소로 이루어집니다.

| 구성 요소 | 설명 |
| --- | --- |
| 하드웨어 구조 | 차체, 외장, 모터 등 물리적인 부품 |
| 구동 시스템 | 모터 드라이버, 전원 관리 장치 |
| 센서 시스템 | 엔코더, IMU, 카메라, LiDAR 등 |
| 제어 시스템 | Raspberry Pi·PC와 운영체제·제어 프로그램 |

URDF는 각 물리 부품을 링크로 기술하고, 조인트로 조립합니다.

### 3. Link 설명

`link`는 로봇의 움직이지 않는 강체 부품을 나타냅니다. `visual`은 화면 표시용 외형이고, `collision`은 물리 충돌 계산용 단순 형상이며, `inertial`은 질량과 관성을 정의합니다.

```xml
<link name="base_link">
  <visual>
    <geometry>
      <box size="0.30 0.20 0.10"/>
    </geometry>
    <material name="blue">
      <color rgba="0 0 1 1"/>
    </material>
  </visual>
  <collision>
    <geometry>
      <box size="0.30 0.20 0.10"/>
    </geometry>
  </collision>
  <inertial>
    <mass value="1.0"/>
    <inertia ixx="0.01" ixy="0" ixz="0" iyy="0.01" iyz="0" izz="0.01"/>
  </inertial>
</link>
```

`origin`의 `xyz`는 평행 이동, `rpy`는 roll·pitch·yaw 회전 오프셋입니다. 복잡한 STL 메시를 `visual`에 사용하더라도 `collision`에는 박스·원통 같은 단순 형상을 사용하면 충돌 계산량을 줄일 수 있습니다.

### 4. Joint 설명

`joint`는 부모 링크와 자식 링크를 연결하고 상대 운동을 정의합니다.

```xml
<joint name="left_wheel_joint" type="continuous">
  <parent link="base_link"/>
  <child link="left_wheel_link"/>
  <origin xyz="0 0.12 0" rpy="0 0 0"/>
  <axis xyz="0 1 0"/>
</joint>
```

| 조인트 유형 | 설명 | 예시 |
| --- | --- | --- |
| `continuous` | 회전 제한 없이 계속 회전 | 바퀴 |
| `revolute` | 각도 제한이 있는 회전 | 로봇 팔 관절 |
| `prismatic` | 축 방향 직선 이동 | 리니어 액추에이터 |
| `fixed` | 상대 운동 없음 | 본체에 장착한 카메라 |
| `floating` | 6자유도 운동 | 특수 용도 |
| `planar` | 평면 운동 | 특수 용도 |

`parent`와 `child`는 연결할 링크, `origin`은 장착 위치와 자세, `axis`는 운동 축, `limit`은 위치·속도·힘 제한을 나타냅니다.

### 5. 완전한 로봇 모델

모든 링크와 조인트를 하나의 `robot` 태그 안에 넣으면 완전한 로봇 모델이 됩니다. URDF를 읽을 때는 먼저 `link`와 `joint` 목록으로 로봇의 구조를 파악한 뒤 각 외형·충돌·관성 값을 확인하는 편이 좋습니다.

```xml
<?xml version="1.0"?>
<robot name="simple_robot">
  <!-- link와 joint 정의 -->
</robot>
```

### 6. 패키지 구조와 모델 시각화

로봇 설명 패키지는 보통 다음 구조를 가집니다.

| 디렉터리 | 내용 |
| --- | --- |
| `urdf` | URDF 또는 Xacro 모델 파일 |
| `meshes` | URDF에서 참조하는 STL·DAE 메시 파일 |
| `launch` | 모델 표시용 Launch 파일 |
| `rviz` | RViz2 설정 파일 |

`yahboomcar_description` 패키지를 작업 영역 `src`에 둔 뒤 빌드합니다.

```bash
colcon build --packages-select yahboomcar_description
source install/setup.bash
```

다음 Launch 파일은 `robot_state_publisher`와 RViz2를 시작해 모델을 표시합니다.

```bash
ros2 launch yahboomcar_description display.launch.py
```

RViz2에서는 `RobotModel` 디스플레이와 TF를 통해 로봇의 링크·조인트 좌표계를 확인할 수 있습니다.
