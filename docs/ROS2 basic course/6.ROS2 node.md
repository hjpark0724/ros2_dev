# 6. ROS2 노드

### 1. 노드 소개

ROS2에서 통신 객체는 노드를 중심으로 구성됩니다. 일반적으로 노드 하나는 하나의 기능 모듈을 담당합니다. 예를 들어 레이더 드라이버 노드는 레이더 메시지를 발행하고, 카메라 드라이버 노드는 이미지 메시지를 발행할 수 있습니다.

완전한 로봇 시스템은 여러 노드가 함께 동작하여 구성됩니다. ROS2에서는 하나의 실행 파일(C++ 프로그램 또는 Python 프로그램)에 하나 이상의 노드를 포함할 수 있습니다.

### 2. 노드 생성 과정

1. 프로그램 파일 만들기
2. 관련 ROS 라이브러리 가져오기
3. 노드 기능 작성하기
4. 구성 파일 작성하기
5. 컴파일 및 실행하기

### 3. Hello World 노드 예제

이 절에서는 Python 패키지를 예로 들어 간단한 ROS2 노드를 만듭니다.

### 3.1. Python 패키지 만들기

작업 영역의 `src` 디렉터리로 이동합니다. `workspace`는 실제 작업 영역 경로로 바꿉니다.

```bash
cd workspace/src
```

`pkg_helloworld_py` Python 패키지와 `helloworld` 실행 파일을 만듭니다.

```bash
ros2 pkg create pkg_helloworld_py --build-type ament_python --dependencies rclpy --node-name helloworld
```

### 3.2. 코드 작성

위 명령을 실행하면 `pkg_helloworld_py` 패키지와 노드 코드를 작성할 `helloworld.py` 파일이 생성됩니다. 기존 `helloworld.py` 내용을 아래 코드로 바꿉니다.

```python
import time

import rclpy
from rclpy.node import Node


class HelloWorldNode(Node):
    """초기화된 뒤 Hello World 로그를 반복 출력하는 노드입니다."""

    def __init__(self, name):
        super().__init__(name)
        while rclpy.ok():
            self.get_logger().info("Hello World")
            time.sleep(0.5)


def main(args=None):
    rclpy.init(args=args)
    node = HelloWorldNode("helloworld")
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

코드를 작성한 뒤 Python 프로그램의 진입점을 시스템에 알려야 합니다. 패키지의 `setup.py` 파일에서 `entry_points`에 다음 항목을 추가합니다.

```python
entry_points={
    'console_scripts': [
        'helloworld = pkg_helloworld_py.helloworld:main',
    ],
},
```

### 3.3. 패키지 컴파일하기

작업 영역 최상위 디렉터리에서 패키지를 컴파일합니다.

```bash
colcon build --packages-select pkg_helloworld_py
```

컴파일이 끝나면 현재 터미널에 작업 영역 환경을 적용합니다.

```bash
source install/setup.bash
```

### 3.4. 노드 실행하기

다음 명령으로 노드를 실행합니다.

```bash
ros2 run pkg_helloworld_py helloworld
```

정상적으로 실행되면 터미널에 `Hello World` 로그가 반복해서 출력됩니다.
