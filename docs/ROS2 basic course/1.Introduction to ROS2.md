# 1. ROS2 소개

## 1. ROS2 개요

ROS2는 2세대 로봇 운영체제(Robot Operating System)로, ROS1의 일부 한계를 개선한 후속 버전입니다. 최초의 ROS2 배포판인 Ardent는 2017년에 출시되었으며, 이후 지속적인 업데이트와 최적화를 거쳐 안정적인 버전들이 제공되고 있습니다.

ROS1과 마찬가지로 ROS2도 사용하는 Linux 버전에 맞는 배포판을 선택해야 합니다. 원문에서 제시한 대응 관계는 다음과 같습니다.

| ROS2 배포판 | 출시 시점 | 유지보수 종료 시점 | Ubuntu 버전 |
| --- | --- | --- | --- |
| Ardent Apalone | 2017.12 | 2018.12 | Ubuntu 16.04 (Xenial Xerus) |
| Bouncy Bolson | 2018.7 | 2019.7 | Ubuntu 16.04 (Xenial Xerus), Ubuntu 18.04 (Bionic Beaver) |
| Crystal Clemmys | 2018.12 | 2019.12 | Ubuntu 18.04 (Bionic Beaver) |
| Dashing Diademata | 2019.5 | 2021.5 | Ubuntu 18.04 (Bionic Beaver) |
| Eloquent Elusor | 2019.11 | 2020.11 | Ubuntu 18.04 (Bionic Beaver) |
| Foxy Fitzroy | 2020.6 | 2023.5 | Ubuntu 20.04 (Focal Fossa) |
| Galactic Geochelone | 2021.5 | 2022.11 | Ubuntu 20.04 (Focal Fossa) |
| Humble Hawksbill | 2022.5 | 2027.5 | Ubuntu 22.04 (Jammy Jellyfish) |
| Iron Irwini | 2023.5 | 2024.11 | Ubuntu 22.04 (Jammy Jellyfish) |
| Jazzy Jalisco | 2024.5 | 2029.5 | Ubuntu 24.04 (Noble Numbat) |

> **참고:** 사용하는 Linux 배포판에 맞는 ROS2 버전을 설치해야 합니다. 이 강좌에서는 Jazzy를 기준으로 설명하며, Jazzy는 Ubuntu 24.04 (Noble Numbat)를 대상으로 합니다. 강좌의 프로그램과 예제는 다른 ROS2 버전에도 적용할 수 있습니다.

## 2. ROS2의 특징

### 2.1. 세 가지 플랫폼 지원

ROS2는 다음 플랫폼을 지원합니다.

- Ubuntu
- Mac OS X
- Windows 10

### 2.2. 분산 아키텍처

마스터 노드가 제거되어 노드 검색, 발행/구독, 요청/응답 통신을 분산 방식으로 수행할 수 있습니다.

### 2.3. 실시간 지원

ROS2는 실시간 처리를 지원합니다.

### 2.4. 새로운 프로그래밍 언어 지원

- C++11
- Python 3.5 이상

### 2.5. 새로운 빌드 시스템 Ament 사용

ROS2는 ROS1의 Catkin 대신 Ament 빌드 시스템을 사용합니다.

### 2.6. ROS1과의 통신

ROS1은 `rosbridge`를 통해 ROS2와 통신할 수 있습니다.

## 3. ROS2와 ROS1의 차이점

### 3.1. 플랫폼

ROS1은 현재 Linux만 지원하며 일반적으로 Ubuntu에서 빌드하고 사용합니다. 반면 ROS2는 Ubuntu와 Windows는 물론 임베디드 개발 보드에서도 빌드하고 사용할 수 있으므로, 더 폭넓은 환경에서 활용할 수 있습니다.

### 3.2. 언어

#### C++

ROS1의 핵심은 C++03을 기반으로 하지만, ROS2는 C++11을 폭넓게 사용합니다.

#### Python

ROS1은 Python 2를 사용합니다. ROS2는 최소 Python 3.5 이상이 필요하며, Foxy는 Python 3.8을 사용합니다.

### 3.3. 미들웨어

ROS1은 실행 전에 `roscore`를 시작해야 하며, 이 마스터가 노드 간 통신을 제어합니다. 반면 ROS2에는 이러한 마스터가 없습니다. 대신 데이터 전송을 위한 추상 미들웨어 인터페이스를 사용합니다.

현재 이 인터페이스의 구현은 DDS 표준을 기반으로 합니다. 이를 통해 ROS2는 다양한 고품질 QoS 정책을 제공하며, 서로 다른 네트워크 환경에서의 통신을 개선합니다.

### 3.4. 빌드 명령

ROS1은 `catkin_make` 명령으로 빌드하고, ROS2는 `colcon build` 명령으로 빌드합니다.
